<img src="https://halitsever-api.vercel.app/api/installation"/>
</a>

Dependency installation:

```bash
npm install
```

Run with dev mode:

```bash
TELEGRAM_BOT_TOKEN=... LANG=<en|tr> npm run dev
```

Run with production mode:

```bash
TELEGRAM_BOT_TOKEN=... LANG=<en|tr> npm run start
```
